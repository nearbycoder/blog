`hackernews-tui` is a simple terminal interface for searching Hacker News fast without leaving your shell.

![hackernews-tui screenshot](/images/hackernews-tui.jpg)

## Why I built it

I wanted a quick CLI workflow for Hacker News discovery where I could search and scan results directly in terminal.

This was also a focused test of how quickly a custom TUI can be shipped now with OpenTUI plus GPT-5.3-Codex.

## Usage

```bash
bunx hackernews-tui
```

```bash
npx hackernews-tui
```
