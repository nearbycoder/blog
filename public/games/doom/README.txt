The .jsdos ZIP bundle contains all 20 original installed shareware files,
including README.TXT, HELPME.TXT, ORDER.FRM and the complete FAQ.
Game files and levels are unmodified. Only .jsdos emulator configuration is added.
No registered/commercial episodes are included.

To reproduce: concatenate DOOMS_19.1 and DOOMS_19.2 from doom19s.zip, extract
the resulting ZIP, and package its files with .jsdos/dosbox.conf and
.jsdos/jsdos.json from shareware.jsdos. The autoexec command starts Episode 1,
Map 1 at skill 2. Original game menus remain accessible with Escape.

Runtime: js-dos 8.4.1 (GPL-2.0), loaded on demand from jsDelivr.
